# Private local inputs

`data/` is reserved for private local CSV inputs. The public repository keeps only this README; the actual data files in this folder are ignored by Git and should stay on your machine.

Place these files here to run the cleaned workflow:

- `covariate_file.csv`
- `msdl_all_subjects_connectivity_edges.csv`
- `genotype_matrix.csv`
- `snp_metadata.csv`

These four files are enough to:

1. generate candidate resilience edges with
   `bash run.sh python scripts/fmriphenotype/get_resilience_edge.py`
2. run the pairwise SNP-connectivity analysis with
   `bash run.sh imggenetics`

## Required file schemas

### `covariate_file.csv`

Used by:

- `scripts/fmriphenotype/get_resilience_edge.py`
- `imggenetics`

Required columns:

- `SubjectId`
- `Age`
- `Sex`
- `Scan_type`
- `Manufacturer`
- `Subtype`

Optional columns:

- `Subject_match_check`
  If present, only rows with `True` are kept.
- `fMRI_Image_ID`
  Allowed but not required by the cleaned workflow.

Expected values:

- `Sex`: `F` or `M`
- `Subtype`: values that normalize to the manuscript groups
  - `Control` or `CN`
  - `Asym AD` or `AsymAD`
  - `Typical AD`, `TypicalAD`, or `TypAD`

### `msdl_all_subjects_connectivity_edges.csv`

Used by:

- `scripts/fmriphenotype/get_resilience_edge.py`
- `imggenetics`

Required structure:

- one subject identifier column
  Recommended: `SubjectId`
- one numeric column per MSDL connectivity edge

Accepted subject-id column names:

- for `imggenetics`: `SubjectId`, `Subject_ID`, `subject_id`, `subject`, `ID`, or `id`
- for `get_resilience_edge.py`: `SubjectId`, `subject_id`, or `subject`

Expected content:

- rows: one subject per row
- edge values: numeric signed connectivity values
- paper workflow: 741 MSDL GraphicalLassoCV edge columns

### `genotype_matrix.csv`

Used by:

- `imggenetics`

Required structure:

- one subject identifier column
  Recommended: `SubjectId`
- remaining columns: numeric SNP dosage columns

Accepted subject-id column names:

- `SubjectId`, `Subject_ID`, `subject_id`, `subject`, `ID`, or `id`

Recommended SNP column naming:

- `rs123456_A`
- `rs987654_G`

The code matches SNPs using the `rs` prefix before the underscore.

### `snp_metadata.csv`

Used by:

- `imggenetics`

Required columns:

- `SNP`
- `Case`
- `Control`

Optional but strongly recommended columns:

- `CHR`
- `BP`
- `P`
- `OR`

Expected content:

- `SNP`: rsID matching the genotype columns, for example `rs123456`
- `Case` and `Control`: subtype labels that normalize to the manuscript groups
- `P` and `OR`: GWAS summary values used in the manuscript-facing output tables

## Generated files that are not inputs

- `model2_candidate_resilience_edges.csv`
  This is generated by Model 2 and written under `outputs/fmriphenotype/`.
- all `outputs/` tables
  These are generated locally and are not versioned.
